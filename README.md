# jsgsHelper 5.0

适用于 `jsgs.study.gspxonline.com` 的浏览器学习播放助手。脚本在当前已登录账号的页面上运行，不包含账号、密码、token 或 cookie，也不需要用户将这些信息填入脚本。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 在 Tampermonkey 中新建脚本，粘贴 [`auto_study_assistant.user.js`](./auto_study_assistant.user.js) 的内容并保存。
3. 用自己的账号登录学习平台，从“我的学习”打开已报名课程。脚本会在课程页显示白色悬浮面板；可以拖动、收起或暂停接管。

## 使用说明

- 当前课程：支持尝试自动播放、课内连播、文件逐页翻阅、静音、倍速及按设定间隔刷新进度。`0` 分钟表示不定时刷新；也可点“立即刷新”。
- 跨课程：在面板“跨课顺序”中输入**自己已报名**课程的数字 ID，按期望顺序以逗号分隔，例如 `991,1088,1072`。离开输入框后保存，刷新页面后更新队列指示。未配置时只处理当前课程，不会把新账号强制送入预置课程。队列仅保存在当前浏览器标签会话，换账号时建议新开标签并重新配置。
- 如需找到课程 ID，可在课程页地址中的 `/study/course/数字` 或 `#/study/learn/数字` 查看。最多支持 30 个 ID。
- 如果浏览器阻止自动播放，请先在页面上手动点一次播放。后台播放、平台学习时长和进度记录受浏览器节流、网络连接及平台服务器规则影响，脚本不能保证离开页面后一定持续计时或获得学时。请返回平台核实实际记录。

脚本不会上传凭据。发布仓库时也请勿提交浏览器导出的 cookie、token、抓包文件或个人课程数据。
